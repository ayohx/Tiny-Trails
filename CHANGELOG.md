# Changelog

All notable changes to Tiny Trails will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added
- Observability foundation with Sentry integration
- Structured logging utilities following HX standards
- Error boundary component for graceful error handling
- Comprehensive test suite with Jest
- Security and privacy documentation

## [1.0.0] - 2024-11-20

### Added
- Phase 1: Core letter tracing functionality
  - Smooth path drawing with Catmull-Rom splines
  - Real-time progress tracking with coverage calculation
  - Celebration overlay with haptic feedback
  - Tiko mascot integration with animations
  - Rainbow gradient drawing mode
  
- Phase 2: Enhanced drawing tools
  - Color picker with 8 colors plus rainbow mode
  - Line thickness controls (4 options: thin, medium, thick, extra)
  - Eraser tool with visual cursor and collision detection
  - Full undo/redo functionality (20 action history limit)
  - Professional toolbar interface (top and bottom)
  - Enhanced stroke data model (color, thickness, timestamp)

### Technical
- React Native with Expo Router architecture
- TypeScript for type safety
- Zustand for state management
- React Native SVG for vector graphics
- Gesture handler for smooth touch interactions
- Reanimated for performant animations
